# Fixture definitions and import

Preserve channel offsets, coarse/fine order, function ranges, RGBW semantics,
calibration and units with characterization tests. Import is data conversion,
not arbitrary execution. Validate addressing/capabilities and retain source,
license and format-loss diagnostics. QXF is an existing implementation; other
formats remain planned until tested. Avoid further coupling fixture parsing to
web startup. The common rig schema belongs to both runtime and preview.
