# Venue geometry and physical state

Keep physics, selection and event generation pure. The host owns leases, clocks, callback execution and caches of prepared geometry. Preserve finite portable bodies and memberships, deterministic ordered pair resolution, substep durations, resource ceilings and pause/rebase behavior. Unit tests should exercise official frame rendering for HDR contacts and ensure observation never changes DMX. Run `lein test afterglow.spatial-test afterglow.render.hdr-test`.
