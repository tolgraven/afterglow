# Push AWT fallback replay

The actual 960 × 160 AWT display renderer received the view produced by the Push 3 profile and the show reducer. The synthetic patch maps Level to a 16-bit pan channel. Injected MIDI simulates a normal step, moving back to zero, holding Shift, one fine step, releasing Shift, and a final normal step. The status strip shows Fine during Shift, and the value renders as `1.5259e-05` after the fine step.

The capture uses the source-identical renderer from `742daf05`, now integrated at `5ebe92bd`. It uses no physical Push or output transport.
