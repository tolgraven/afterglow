## Independent checks

**Rendering and output ownership.** Traced patch compilation, coarse/fine packing, photometry, dense emission, native layer gain and HDR. The patch validator accepted a lamp with an explicit nil `:emission-color`, but dense compilation tried to cast its missing color components to doubles. Compilation now normalizes the tint once, and a regression compares physical bytes plus rich and compact projections with a white reference lamp. [Fix](https://github.com/tolgraven/afterglow/commit/c929025)

**GPU lifecycle.** Reviewed expression and moving-head owners, native context creation, GL fence and readback, deadline fallback and destruction. A second instance of the historical expression-session timeout race affected moving-head renders. Both owners now release the executor termination lock before calling the driver and retain the actual teardown result in their completion promise. Deterministic tests forced idle-worker shutdown and a blocked driver destructor. Both tests failed on the baseline and passed after the fix. [Fix](https://github.com/tolgraven/afterglow/commit/c929025)

**Fog calibration.** Ran the live plume model with 18-second room clearance, a 60-second mixing time and a 3 m sightline. The unmetered 84-second recording now asks for a longer scan. The same recording with metered flows recovers the room’s clearance half-life within 1.5 seconds. [Regression](https://github.com/tolgraven/afterglow/blob/c929025/test/afterglow/render/atmosphere/calibration_test.clj)

**Timing, DMX and protocol boundaries.** Traced frame timestamps, publication gates, retirement of old universes, OLA write deadlines and partial writes, ArtDMX address/sequence packing, RDM ACK_TIMER and queued reply correlation, and timestamps across MIDI queues. The protocol regression suite uses local sockets and injected clocks. It covered 21 tests and 162 assertions for the scheduler, RDM and MIDI sync. [Transport fixes](https://github.com/tolgraven/afterglow/commit/005cbb3)

**Dependencies.** Audited the baseline Leiningen classpath and Afterglow’s npm lockfile against OSV. Eight resolved Maven coordinates matched advisories. The GPU profile opts into JOGL and GlueGen 2.6.0. The remediation pins JVM dependencies in `project.clj`. [Dependency fixes](https://github.com/tolgraven/afterglow/commit/6c6e60a)

## Verification

The historical runtime, color and device fixes passed 49 tests with 320 assertions. A further 20 tests with 95 assertions exercised color-wheel boundaries, failed hot-reload retries and visible Push sync-lock feedback. [Fixes](https://github.com/tolgraven/afterglow/commit/dc5c30e)

The renderer regressions passed in 73 CPU tests with 3,758 assertions. The native suite passed in 20 tests with 6,301 assertions on Mesa 25.0.7 llvmpipe, OpenGL 4.5. The fog regression uses modeled pump output and synthetic camera observations. Physical fluid, DMX interfaces, controller hardware and macOS drivers require separate measurements.
