# Afterglow control, import and device boundaries

Reviewed master `7da8eab`. Fixes are on `codex/master-review-remediation`. Scope included production entry points, parser and queue ownership, direct callers, saved registrations and targeted tests. The checks used static inspection, pure handler calls, injected MIDI/RDM, DMX capture, and an existing loopback OLA fixture. No physical shows, devices, public hosts or third-party systems were contacted.

| Boundary | Evidence and resolution |
| --- | --- |
| Embedded web control and JVM REPL | `src/afterglow/web/routes/home.clj` exposes the operator console and show commands. The console calls `eval` by design at `src/afterglow/web/routes/web_repl.clj:87`. The master handler had anti-forgery protection but no access gate. `core/start-web-server` passed only a port to HTTP Kit 2.8.1, whose default bind address is `0.0.0.0`. `63230d9` adds `afterglow.web.access/wrap-operator`, which gates the entire Ring app before document parsing or routing. Default HTTP and optional nREPL bind to loopback. Token-free HTTP checks the socket peer and original Host authority and rejects X-Forwarded-For, which HTTP Kit can use to derive the Ring remote address. An explicitly configured nonlocal bind requires an operator password and challenges every request, including local requests. The password is stripped before downstream handling. An authenticated operator retains full console privileges. Basic credentials require TLS or an encrypted tunnel on untrusted networks. |
| Saved reactive handlers | Master `src/afterglow/reactive/registry.clj:85` used `requiring-resolve` on every saved Var symbol, even when the caller withheld trust from inline Clojure. `ecabf65` checks exact ID, handler kind and Var descriptor against a local registration (optionally a previous in-process owner) before reusing a handler. A new Var needs an explicit qualified-symbol allowlist or trusted import. Staged validation precedes graph replacement. Bare data from an imported file cannot provide the local owner. Inline source still requires explicit trust, binds reader evaluation off, and must consist of one function form. |
| QLC+ fixture definition import | `src/afterglow/fixtures/qxf.clj`, `resources/templates/fixture-definition.clj.template`. XML text was interpolated as source into Clojure literals and output filenames were derived directly from the model name. A preflight existence check preceded a separate overwrite-capable write. `f1cb64f` quotes metadata according to Clojure reader rules, validates a fixture identifier as a single basename, and uses `CREATE_NEW` to preserve existing files at the write boundary. The project pins Clojure 1.12.7, whose default `clojure.xml/parse` disables external entity resolution. The CLI requests a local file and writes generated source for operator review. Tests read generated Clojure as data and check preservation of operator edits. |
| Physical output gate | `src/afterglow/output/scheduler.clj:26`, PR #17. A bright send could still finish after gate-change acknowledgment because only the publisher took the send lock. `005cbb3` rechecks and installs gate transitions under the publication lock. Rendering against an unchanged gate stays independent. Stale completions are rejected by generation; a new gate starts with its compiled idle output. A blocking capture sink verifies the ordering. |
| RDM delayed SET/GET | `src/afterglow/rdm/transport.clj:47`, PR #17. Queue ACK and NACK now correlate by command class, PID and subdevice. Unrelated queue replies are consumed. A NACK of QUEUED_MESSAGE itself is explicit. Cancellation is checked during the responder's ACK_TIMER delay, as well as before requests, with one absolute timeout and a bounded queue-poll count. `005cbb3` includes these fixes and injected transport tests. `rdm/codec.clj:104` bounds OLA message size before allocation; the parser and decoder check lengths, RPC IDs, response types and UIDs when present. |
| MIDI capture and adapters | `src/afterglow/sync/midi.clj:77`, `src/afterglow/sync.clj:104`, PR #18. The owner used queue processing time for mapped controls whereas observations used capture time. `005cbb3` preserves capture time in both the event and adapter time argument. The control codec checks message length and data bytes. Real-time input and external IO have bounded queues; tests cover disconnected or cancelled ownership. |
| OSC, Art-Net and Link | `afterglow.control.codecs.osc/command` interprets an explicit path mapping, requires an envelope and validates semantic operations. The Overtone OSC listener and operator-defined OSC callbacks are trusted show-network boundaries without per-message authentication. Art-Net emits bounded channel data on the show network. Carabiner uses loopback TCP, an 8 KiB line bound and EDN status with value checks in `src/afterglow/sync/ableton_link.clj`. The review did not establish guarantees for third-party OSC or Beat Link decoders or device firmware. |
